# 炎色反応あて（enshoku-ate）

炎の色を見て、その色を出す元素を当てる1日5問の学習ゲーム（元素から炎の色を選ぶ問題もある）。正解したら、その元素のなかま（アルカリ金属・アルカリ土類金属・そのほか）も選ぶ。花火の色・炎色反応のしくみと歴史の問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/enshoku-ate/>

- 中身は名古屋市科学館「炎色反応」 <https://www.ncsm.city.nagoya.jp/exhibit_files/pdf/S519.pdf> と、岩手県立総合教育センター「綿棒を使った炎色反応」 <https://www1.iwate-ed.jp/07tantou/kagaku/kagakukiso/kagakukiso%202/sapoto06.pdf> に書いてあることだけです（2026-11-24 に読みました）。2つの資料で言い方が少しちがう色は両方を書きました。
- このゲームは炎の色と元素を知る練習で、実験のやり方は教えません。火を使う実験は、学校で先生といっしょに行ってください。
